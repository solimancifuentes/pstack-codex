# Privacy

This release contains skills and optional local helper scripts. It includes no
publisher-operated MCP server, analytics collector, or telemetry endpoint.
The publisher does not receive your local profile or task files through a
service supplied by this package.

ChatGPT, Codex, Dots, GitHub, and other tools used during a workflow process data
under their own terms, permissions, and account settings. The instructions can
ask those tools to read code and create outputs within the task's authority.
Review their data controls before supplying private material.

Optional helpers store preferences and task records in selected local paths.
GitHub helpers contact GitHub when invoked using the user's existing tools and
authentication. Explicit dependency preparation contacts the configured package
registry. Maintainer upstream checks contact the original GitHub repository.

Support emails contain the information you choose to send. GitHub support
issues are public. Do not include secrets or private data in issues or examples.
Privacy questions may be sent to contact@solimancifuentes.com.
