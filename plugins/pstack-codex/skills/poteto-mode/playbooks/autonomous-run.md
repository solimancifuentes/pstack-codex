### Autonomous run

Read the [shared runtime contract](../../../CODEX.md) for delegation, authority, models, history, helpers, and session limits.

**You own the exit condition. Define done, then drive to it without stopping.**

1. State the exit condition as a checkable predicate before the first iteration (tests green, repro fixed, all N PRs merged, pixel-diff zero).
2. Select a real execution mechanism under CODEX.md. Run iterations within the actual host lifetime. Codex uses the active turn by default and creates a goal only on an explicit goal request. A Dot may coordinate native background tasks for a requested ongoing responsibility when the environment is configured. Create a saved schedule, heartbeat, or event subscription only when requested, after checking for an existing match. A shell watcher or collaboration child does not wake a completed chat or survive a restart by guarantee. Without a durable runner, keep a resumable checkpoint and state that limit.
3. Each iteration makes the smallest change the evidence justifies, verifies it against the predicate, commits if it advanced, discards changes that didn't help. Belt-and-suspenders that "might help" gets reverted, not left to ride.
   Sequence the work via the **sequence-verifiable-units** principle skill, verifying each unit before the next instead of batching checks at the end.
4. Mid-run discoveries are yours. Address blockers within the authorized task. Keep unrelated discoveries as evidence-backed follow-ups. Prepare a separate repair only when authorized; an autonomous run does not widen scope or authorize global skill updates. Do not park reversible work for the human or use an available user-input tool or concise chat question. Surface only irreversible actions, genuine product or preference calls no experiment can settle, or a real dead end. Keep the predicate as the main drive, and return to it after each side fix.
5. Checkpoint every iteration via the **show-me-your-work** skill, a row for what changed and whether the predicate moved.
6. Stop when the predicate is met. A plateau is not a stop, so keep going and pivot your approach to push past it. Surface a genuine dead end rather than spinning, and never relax the predicate to declare victory.

**Reply:** the exit condition, iterations run, what landed, what was discarded, final predicate state.
