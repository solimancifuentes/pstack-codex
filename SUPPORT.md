# Support

Open an issue at https://github.com/solimancifuentes/pstack-codex/issues or
contact Soliman Cifuentes at contact@solimancifuentes.com.

Include the plugin version, host, operating system, invocation, expected result,
and a minimal reproduction. Remove credentials, private repository content,
personal profiles, and unrelated chat history before sharing diagnostics.
GitHub issues are public. There is no promised support response time.
